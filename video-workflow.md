# Workflow создания AI-видео: от идеи до готового ролика

## Этап 1: Подготовка (30-60 минут)

### 1.1 Сценарий
- Напиши короткий сценарий (30-90 секунд для начала)
- Раздели на сцены по 3-5 секунд каждая
- Опиши каждую сцену детально (что происходит, освещение, ракурс)

**Пример структуры:**
```
Сцена 1 (5 сек): Крупный план - мужчина в офисе смотрит в окно, дождливый день
Сцена 2 (4 сек): Средний план - он берет телефон со стола
Сцена 3 (5 сек): Крупный план экрана телефона - входящее сообщение
```

### 1.2 Промпты для генерации
Преобразуй каждую сцену в детальный промпт:

**Формула хорошего промпта:**
```
[Тип кадра] [Действие] [Персонаж/объект] [Окружение] [Освещение] [Стиль] [Движение камеры]
```

**Пример:**
```
Close-up shot, a tired businessman in his 40s looking through rainy office window, 
modern office interior, soft natural lighting, cinematic style, slow camera push in
```

## Этап 2: Генерация видео (1-3 часа)

### 2.1 Выбор инструмента

**Для реалистичных сцен:**
- Runway Gen-3 (лучшее качество)
- Luma Dream Machine (хорошая альтернатива)

**Для стилизованных/анимационных:**
- Pika Labs (больше контроля над стилем)
- Kling AI (хорош для азиатской эстетики)

### 2.2 Процесс генерации

1. **Регистрация:**
   - Runway: https://runwayml.com (125 кредитов бесплатно)
   - Luma: https://lumalabs.ai (30 генераций/месяц)
   - Pika: https://pika.art (через Discord)

2. **Генерация каждой сцены:**
   - Генерируй 3-5 вариантов каждой сцены
   - Выбирай лучший результат
   - Сохраняй все в отдельную папку

3. **Советы по генерации:**
   - Начинай с ключевых сцен
   - Используй seed для консистентности
   - Если персонаж - сначала сгенерируй референс в Midjourney/DALL-E

### 2.3 Консистентность персонажей

**Метод 1: Image-to-Video**
- Создай референс персонажа в Midjourney
- Используй этот референс для всех сцен через img2video

**Метод 2: Детальное описание**
- Используй одинаковое описание персонажа во всех промптах
- Пример: "30-year-old man, short brown hair, blue eyes, grey suit"

## Этап 3: Пост-продакшн (1-2 часа)

### 3.1 Монтаж в CapCut

**Скачать:** https://www.capcut.com

**Шаги:**
1. Импортируй все сгенерированные клипы
2. Расставь в нужном порядке
3. Обрежь лишнее (оставь лучшие моменты)
4. Добавь переходы между сценами

**Рекомендуемые переходы:**
- Dissolve (растворение) - для плавных переходов
- Cut (резкий) - для динамичных моментов
- Match cut - если есть похожие элементы

### 3.2 Звук

**Музыка (бесплатные источники):**
- Pixabay Music: https://pixabay.com/music/
- YouTube Audio Library
- Uppbeat: https://uppbeat.io

**Звуковые эффекты:**
- Freesound.org
- Zapsplat.com
- AI генерация: ElevenLabs (звуки), Suno (музыка)

**Озвучка:**
- ElevenLabs (10k символов бесплатно/месяц)
- Play.ht (бесплатный план)
- Или запиши свой голос

### 3.3 Финальная обработка

**В CapCut:**
1. **Цветокоррекция:**
   - Используй пресеты или настрой вручную
   - Сделай единый стиль для всех сцен

2. **Субтитры (если нужны):**
   - CapCut → Text → Auto captions
   - Выбери стиль (для TikTok/Reels есть трендовые)

3. **Эффекты:**
   - Не переборщи
   - Zoom, glitch, blur - по вкусу

4. **Экспорт:**
   - 1080p для YouTube/Instagram
   - 60 FPS если AI сгенерировал в таком качестве
   - Формат MP4

## Этап 4: Улучшение качества (опционально)

### 4.1 Апскейл видео
- Topaz Video AI (платный, но лучший)
- CapCut имеет встроенный AI upscale
- Runway также может апскейлить

### 4.2 Стабилизация
Если видео дрожит:
- CapCut → Stabilization
- DaVinci Resolve (бесплатная версия)

### 4.3 Удаление артефактов
- Вырезай проблемные кадры
- Используй motion blur для маскировки
- Добавь эффекты поверх проблемных мест

## Практический пример: Создание 30-сек ролика

### Концепт: "Утро программиста"

**Сцены:**
1. (5с) Будильник звонит, рука выключает его
2. (4с) Человек встает с кровати, потягивается
3. (5с) Идет на кухню, включает кофемашину
4. (4с) Открывает ноутбук
5. (5с) Печатает код, на экране появляется "Hello World"
6. (4с) Довольная улыбка, пьет кофе
7. (3с) Титры/лого

**Промпты для Runway:**
```
1. "Close-up shot of alarm clock ringing at 7:00 AM, hand reaching to turn it off, 
   morning sunlight, cinematic, slow motion"

2. "Medium shot of young programmer getting out of bed, stretching arms, 
   messy bedroom, soft morning light, realistic style"

3. "Tracking shot following person walking to kitchen, turning on coffee machine, 
   modern apartment, warm lighting, cinematic"

4. "Over shoulder shot of hands opening MacBook laptop, reflection in screen, 
   wooden desk, natural light from window"

5. "Screen recording style, code editor with 'Hello World' being typed, 
   VS Code interface, dark theme, smooth typing animation"

6. "Close-up portrait of satisfied programmer smiling, holding coffee mug, 
   soft focus background, warm color grading, cinematic"

7. "Animated text logo appearing on clean background, modern typography, 
   smooth fade in animation"
```

**Тайминг работы:**
- Написание сценария: 20 мин
- Генерация 7 сцен (по 3 варианта): 1.5 часа
- Монтаж в CapCut: 40 мин
- Звук и музыка: 30 мин
- Финальная обработка: 20 мин

**Итого: ~3 часа**

## Частые проблемы и решения

### Проблема 1: Персонаж меняется между сценами
**Решение:**
- Используй один референс для всех сцен
- Генерируй лицо в Midjourney, потом img2video
- Или снимай крупные планы без лица

### Проблема 2: Странные движения/артефакты
**Решение:**
- Генерируй короткие клипы (3-5 сек)
- Вырезай проблемные кадры
- Используй переходы для маскировки
- Добавь motion blur

### Проблема 3: Кончились бесплатные кредиты
**Решение:**
- Используй несколько сервисов параллельно
- Создавай новые аккаунты (временные email)
- Комбинируй AI-видео со стоковыми кадрами
- Используй статичные AI-изображения + Ken Burns эффект

### Проблема 4: Низкое качество
**Решение:**
- Пиши более детальные промпты
- Используй референсы (img2video)
- Апскейль в CapCut или Topaz
- Добавь film grain для "кинематографичности"

## Продвинутые техники

### 1. Комбинирование инструментов
```
Midjourney (референсы) → Runway (видео) → CapCut (монтаж) → Topaz (апскейл)
```

### 2. Использование ControlNet
Для точного контроля композиции (требует технических навыков)

### 3. AI-актеры
- HeyGen для говорящих персонажей
- D-ID для анимации фото
- Комбинируй с Runway для фоновых сцен

### 4. Создание сериала
- Создай "библиотеку" персонажей (референсы)
- Используй одинаковые локации
- Генерируй по эпизоду в неделю
- Собирай feedback и улучшай процесс
