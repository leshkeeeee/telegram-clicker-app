## 🎮 Игровая механика

### Энергия
- Старт: **1000 энергии**
- Восстановление: **1 энергия/сек** (улучшается)
- Стоимость тапа: **1 энергия** (масштабируется)

### Улучшения

| Улучшение | Эффект | Базовая цена | Множитель |
|-----------|--------|--------------|-----------|
| 🔋 Энергия | +50% к максимуму | 100 💎 | x1.8 |
| ⚡ Сила тапа | +50% за тап | 50 💎 | x1.6 |
| 🤖 Авто-ферма | +10 монет/час | 500 💎 | x2.0 |
| ⚡ Восстановление | +50% скорости | 200 💎 | x1.7 |

### Достижения

| Достижение | Условие | Награда |
|------------|---------|---------|
| 👆 Первый тап | 1 тап | 10 💎 |
| 🔥 Таппер | 100 тапов | 50 💎 |
| ⚡ Про таппер | 1000 тапов | 200 💎 |
| 💰 Первая тысяча | 1000 монет | 100 💎 |
| 💎 Богач | 10000 монет | 500 💎 |
| 🏆 Уровень 5 | Достичь 5 уровня | 250 💎 |
| 👑 Уровень 10 | Достичь 10 уровня | 1000 💎 |

### Формула уровня
```javascript
уровень = floor(log10(баланс + 1) * 2) + 1
```

## 📱 Деплой в Telegram

### Шаг 1: Выберите хостинг (бесплатно)

#### GitHub Pages (рекомендуется)
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ВАШ_USERNAME/crypto-clicker.git
git push -u origin main

# Включите GitHub Pages в Settings → Pages
```

#### Или используйте:
- **Vercel**: `vercel`
- **Netlify**: `netlify deploy --prod`
- **Cloudflare Pages**: через веб-интерфейс

### Шаг 2: Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Введите имя бота (например: `Crypto Clicker`)
4. Введите username (например: `CryptoClickerBot`)
5. Сохраните токен

### Шаг 3: Создайте Mini App

1. Отправьте `/newapp` в BotFather
2. Выберите вашего бота
3. Введите название: `Crypto Clicker`
4. Введите описание: `Тапай и зарабатывай крипту! Улучшай силу и соревнуйся с друзьями.`
5. Загрузите фото 640x360px
6. **Введите URL** вашего приложения (с GitHub Pages/Vercel/Netlify)
7. Введите короткое имя: `clicker`
8. Готово! 🎉

### Шаг 4: Протестируйте

Откройте вашего бота в Telegram и нажмите кнопку запуска приложения!

Подробная инструкция в **DEPLOY.md**

## 🐛 Частые проблемы

### Приложение не загружается в Telegram
- Проверьте, что URL использует HTTPS
- Убедитесь, что нет CORS ошибок
- Проверьте консоль браузера

### Haptic не работает
- Это нормально в браузере
- Работает только в официальном Telegram клиенте

### Прогресс не сохраняется
- Проверьте, что localStorage доступен
- Включите хранилище для Mini Apps в настройках Telegram

### Анимации тормозят
- Уменьшите количество частиц в `app.js` (строка ~200)
- Закомментируйте `this.initParticles()` для отключения фона
