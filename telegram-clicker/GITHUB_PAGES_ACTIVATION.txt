ШАГ 1: ОТКРОЙТЕ НАСТРОЙКИ РЕПОЗИТОРИЯ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Откройте в браузере:
   https://github.com/leshkeeeee/telegram-clicker-app

2. Нажмите на вкладку "Settings" (⚙️ Настройки)
   Она находится в верхнем меню справа

3. В левом боковом меню найдите раздел "Pages"
   Он находится в секции "Code and automation"

Или просто откройте прямую ссылку:
👉 https://github.com/leshkeeeee/telegram-clicker-app/settings/pages

═══════════════════════════════════════════════════════════════

ШАГ 2: НАСТРОЙТЕ SOURCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

На странице GitHub Pages вы увидите:

┌─────────────────────────────────────────────────────────────┐
│ Build and deployment                                        │
│                                                             │
│ Source                                                      │
│ ┌─────────────────────────────────────────────────────┐   │
│ │ Deploy from a branch                          ▼     │   │
│ └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘

ВАЖНО! Нажмите на выпадающий список и выберите:
✅ "GitHub Actions"

НЕ выбирайте "Deploy from a branch"!

После выбора страница автоматически сохранится.

═══════════════════════════════════════════════════════════════

ШАГ 3: ЗАПУСТИТЕ WORKFLOW (АВТОМАТИЧЕСКИ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

После выбора "GitHub Actions":

1. GitHub автоматически запустит workflow
2. Перейдите на вкладку "Actions":
   https://github.com/leshkeeeee/telegram-clicker-app/actions

3. Вы увидите запущенный workflow:
   "Deploy to GitHub Pages"

4. Статусы:
   🟡 Желтый кружок = в процессе (подождите)
   ✅ Зеленая галочка = успешно!
   ❌ Красный крестик = ошибка

Время выполнения: 1-2 минуты

═══════════════════════════════════════════════════════════════

ШАГ 4: ПРОВЕРЬТЕ РЕЗУЛЬТАТ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

После успешного деплоя (зеленая галочка ✅):

1. Откройте в браузере:
   https://leshkeeeee.github.io/telegram-clicker-app/

2. Вы должны увидеть:
   • Заголовок "Crypto Clicker"
   • Баланс: 0 💎
   • Энергия: 1000/1000 ⚡
   • Большую кнопку для тапов

3. Попробуйте нажать на монету - должны появиться:
   • Анимация
   • +1 к балансу
   • Вибрация (если на телефоне)

✅ РАБОТАЕТ? Отлично! Переходите к созданию бота!

❌ ЕСЛИ НЕ РАБОТАЕТ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Проблема 1: Страница показывает 404
→ Подождите еще 1-2 минуты
→ Очистите кэш браузера (Ctrl+F5)
→ Проверьте что workflow завершился успешно

Проблема 2: Workflow не запускается
→ Убедитесь что выбрали "GitHub Actions", а не "Deploy from a branch"
→ Проверьте что репозиторий публичный (Public)
→ Попробуйте создать пустой коммит:
  git commit --allow-empty -m "Trigger Pages"
  git push origin main

Проблема 3: Workflow завершился с ошибкой (❌)
→ Нажмите на workflow в Actions
→ Посмотрите логи ошибок
→ Обычно помогает повторный запуск (кнопка "Re-run jobs")

Проблема 4: Нет доступа к Settings
→ Убедитесь что вы владелец репозитория
→ Или попросите владельца активировать Pages

💡 АЛЬТЕРНАТИВА: ЛОКАЛЬНОЕ ТЕСТИРОВАНИЕ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Пока GitHub Pages не активирован, используйте локальный сервер:

1. Сервер уже запущен на:
   http://localhost:8000

2. Откройте в браузере и протестируйте игру

3. Для Telegram бота измените URL в bot.py:
   WEB_APP_URL = "http://localhost:8000"

   ⚠️ ВАЖНО: Локальный URL не будет работать в Telegram!
   Telegram требует HTTPS URL (GitHub Pages)
