🚀 ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС:

ВАРИАНТ 1: Запуск с ботом (РЕКОМЕНДУЕТСЯ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Шаг 1: Установите библиотеку
   pip install python-telegram-bot

Шаг 2: Создайте бота в @BotFather
   1. Откройте @BotFather в Telegram
   2. Отправьте: /newbot
   3. Имя: Crypto Clicker Game
   4. Username: your_crypto_clicker_bot
   5. СКОПИРУЙТЕ ТОКЕН!

Шаг 3: Настройте бота
   1. Откройте файл: bot.py
   2. Найдите: TOKEN = "YOUR_BOT_TOKEN"
   3. Замените YOUR_BOT_TOKEN на ваш токен
   4. Сохраните файл

Шаг 4: Активируйте GitHub Pages
   1. Откройте: https://github.com/leshkeeeee/telegram-clicker-app/settings/pages
   2. Source: GitHub Actions
   3. Подождите 1-2 минуты

Шаг 5: Запустите бота
   python bot.py

Шаг 6: Откройте бота в Telegram
   1. Найдите вашего бота
   2. Отправьте /start
   3. Нажмите "🎮 Play Crypto Clicker"
   4. ИГРАЙТЕ! 🎮

🐛 РЕШЕНИЕ ПРОБЛЕМ:

❌ Приложение не открывается?
   → Активируйте GitHub Pages
   → Подождите 1-2 минуты
   → Проверьте URL

❌ Бот не отвечает?
   → Проверьте токен в bot.py
   → Убедитесь что бот запущен
   → Проверьте интернет

❌ /newapp не работает?
   → Используйте /setmenubutton
   → Или запустите bot.py
   → Обновите Telegram

❌ Не сохраняется прогресс?
   → Проверьте localStorage
   → Очистите кэш браузера
   → Откройте в Telegram (не в браузере)

Подробнее: TELEGRAM_BOT_SETUP.txt
