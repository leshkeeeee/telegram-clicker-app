🚀 СЛЕДУЮЩИЕ ШАГИ (7 минут):

ШАГ 1: Активируйте GitHub Pages (2 минуты)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Откройте: https://github.com/leshkeeeee/telegram-clicker-app/settings/pages
2. В разделе "Build and deployment":
   - Source: выберите "GitHub Actions"
3. Подождите 1-2 минуты
4. Ваше приложение будет доступно по адресу:

   🌐 https://leshkeeeee.github.io/telegram-clicker-app/

ШАГ 2: Создайте Telegram бота (3 минуты)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Откройте @BotFather в Telegram: https://t.me/BotFather
2. Отправьте команду: /newbot
3. Введите имя бота: Crypto Clicker Game
4. Введите username: your_crypto_clicker_bot
   (должен заканчиваться на "bot")
5. Сохраните токен бота (на всякий случай)

ШАГ 3: Создайте Mini App (2 минуты)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. В BotFather отправьте: /newapp
2. Выберите вашего бота из списка
3. Введите название: Crypto Clicker
4. Введите описание:

   💎 Качественная тапалка с системой улучшений!

   ⚡ Тапай, прокачивайся, зарабатывай!
   🚀 Офлайн заработок
   🎯 Достижения и статистика

5. Загрузите иконку 512x512px
   (можно создать на https://www.canva.com)
6. Введите URL приложения:

   https://leshkeeeee.github.io/telegram-clicker-app/

7. Short name: clicker

ШАГ 4: Запустите игру! 🎉
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Откройте вашего бота в Telegram и нажмите кнопку запуска!

🐛 РЕШЕНИЕ ПРОБЛЕМ:

❌ Приложение не открывается?
   → Проверьте что GitHub Pages активирован
   → Подождите 1-2 минуты после активации
   → Проверьте URL (без лишних слешей)

❌ Не работает Telegram API?
   → Откройте приложение внутри Telegram
   → Проверьте что скрипт telegram-web-app.js подключен
   → Используйте тестовую страницу для диагностики

❌ Не сохраняется прогресс?
   → Проверьте localStorage в браузере
   → Убедитесь что CloudStorage API доступен
   → Очистите кэш и попробуйте снова

Больше решений в TELEGRAM_SETUP.md!
