📱 ДЕПЛОЙ В TELEGRAM:

1. Задеплойте на GitHub Pages / Vercel / Netlify
2. Откройте @BotFather в Telegram
3. /newbot - создайте бота
4. /newapp - создайте Mini App
5. Введите URL вашего приложения
6. Готово! 🎉
