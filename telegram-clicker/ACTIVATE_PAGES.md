# 🚀 Активация GitHub Pages - 2 минуты

## Проблема
Workflow выполняется успешно ✅, но сайт показывает 404

## Решение
GitHub Pages нужно активировать вручную в настройках репозитория.

---

## Шаги активации

### 1. Откройте настройки Pages
Перейдите по ссылке:
```
https://github.com/leshkeeeee/telegram-clicker-app/settings/pages
```

### 2. Выберите источник деплоя
В разделе **"Build and deployment"** → **"Source"**:
- Нажмите на выпадающий список
- Выберите: **"GitHub Actions"**
- ❌ НЕ выбирайте "Deploy from a branch"

### 3. Подождите
- Страница автоматически сохранится
- Подождите 1-2 минуты
- GitHub Pages активируется автоматически

### 4. Проверьте результат
Откройте в браузере:
```
https://leshkeeeee.github.io/telegram-clicker-app/
```

Должна открыться игра "Crypto Clicker" ✅

---

## Если не работает

### Проблема: Нет доступа к Settings
- Убедитесь что вы владелец репозитория
- Или попросите владельца активировать Pages

### Проблема: Всё равно 404
1. Очистите кэш браузера (Ctrl+F5)
2. Подождите еще 2-3 минуты
3. Проверьте что выбрали "GitHub Actions", а не "Deploy from a branch"

### Проблема: Репозиторий приватный
- GitHub Pages для приватных репозиториев требует платный план
- Сделайте репозиторий публичным (Settings → General → Danger Zone → Change visibility)

Когда сайт заработает:
1. Скопируйте URL: `https://leshkeeeee.github.io/telegram-clicker-app/`
2. Откройте @BotFather в Telegram
3. Создайте Mini App с этим URL
4. Готово! 🎉

Подробная инструкция: `TELEGRAM_SETUP.md`
