# 🤖 Запуск Telegram бота для Mini App

## 🚀 БЫСТРЫЙ СТАРТ (3 шага)

### Шаг 1: Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 2: Получите токен бота

1. Откройте @BotFather в Telegram
2. Отправьте: `/newbot`
3. Введите имя: `Crypto Clicker Game`
4. Введите username: `your_crypto_clicker_bot`
5. **СКОПИРУЙТЕ ТОКЕН** (выглядит как: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 3: Запустите бота

1. Откройте файл `bot.py`
2. Найдите строку: `TOKEN = "YOUR_BOT_TOKEN"`
3. Замените `YOUR_BOT_TOKEN` на ваш токен
4. Сохраните файл
5. Запустите:

```bash
python bot.py
```

## ✅ Готово!

Теперь:
1. Откройте вашего бота в Telegram
2. Отправьте `/start`
3. Нажмите кнопку **🎮 Play Crypto Clicker**
4. Игра откроется!

## 🐛 Решение проблем

### Ошибка: "No module named 'telegram'"
```bash
pip install python-telegram-bot
```

### Ошибка: "Invalid token"
- Проверьте что скопировали токен полностью
- Токен должен быть в кавычках: `TOKEN = "1234567890:ABC..."`

### Бот не отвечает
- Убедитесь что бот запущен (python bot.py)
- Проверьте что токен правильный
- Проверьте интернет соединение

### Кнопка не открывает игру
- Убедитесь что GitHub Pages активирован
- Проверьте URL: https://leshkeeeee.github.io/telegram-clicker-app/
- Подождите 1-2 минуты после активации Pages

## 🌐 Деплой на сервер (опционально)

### Heroku
```bash
# Создайте Procfile
echo "web: python bot.py" > Procfile

# Деплой
git add .
git commit -m "Add bot"
git push heroku main
```

### VPS (Ubuntu)
```bash
# Установите Python
sudo apt update
sudo apt install python3 python3-pip

# Установите зависимости
pip3 install -r requirements.txt

# Запустите в фоне
nohup python3 bot.py &
```
