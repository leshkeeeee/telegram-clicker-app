ШАГ 1: РЕГИСТРАЦИЯ/ВХОД
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Откройте: https://vercel.com/signup
2. Нажмите "Continue with GitHub"
3. Авторизуйтесь через GitHub
4. Разрешите доступ к репозиториям

ШАГ 2: ИМПОРТ ПРОЕКТА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. На главной странице Vercel нажмите:
   "Add New..." → "Project"

2. Найдите в списке репозиториев:
   "leshkeeeee/telegram-clicker-app"

3. Нажмите "Import" справа от репозитория

🤖 СЛЕДУЮЩИЙ ШАГ: СОЗДАНИЕ TELEGRAM БОТА
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

После успешного деплоя на Vercel:

1. Откройте @BotFather в Telegram
2. Отправьте: /newbot
3. Создайте бота
4. Скопируйте токен
5. Откройте bot.py
6. Вставьте:
   - TOKEN = "ваш_токен"
   - WEB_APP_URL = "ваш_vercel_url"
7. Запустите: python bot.py

Подробная инструкция: BOT_SETUP.md
